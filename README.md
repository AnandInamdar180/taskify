Taskify - Personal Task Manager

A modern and responsive task management web application built using HTML, CSS, and JavaScript. Taskify helps users organize, prioritize, and manage their daily tasks efficiently with multiple task views, calendar integration, and productivity tracking.

⸻

Features

* User Login & Registration UI
* Dashboard with productivity insights
* Task Management System
* Interactive Calendar View
* Kanban Board
* Search & Filter Tasks
* Priority-based Task Organization
* Fully Responsive Design
* Modern UI with Light/Dark Theme Support
* Add, Edit & Manage Tasks
* Productivity Statistics

⸻
